# 声音空间 · 多用途声音组合平台

更新时间：2026-10-28。当前是可以在本地运行的网页应用，采用简洁界面，围绕专注、学习、放松、休息、睡前和自由组合组织功能。

已实现：首页与场景筛选、13 个内置方案、方案详情、10 秒预听、播放与暂停、阶段跳过／延长、音量和声音比例、低亮显示、最多四层的自由组合，以及收藏和个人方案保存。首页已加入自然视觉与快捷开始，独立理念页 `#/about` 提供平台目标、声音原理及可展开的研究参考。研究依据在详情中展开，不要求用户填写研究问卷或使用效果反馈。

## 本地运行

需要 Node.js 22 或以上，无第三方安装依赖。macOS 可在项目文件夹双击 `启动声音空间.command`：启动后台服务并打开浏览器，再次启动会复用同一服务。固定使用 127.0.0.1:4173，避免更换地址后找不到本地方案。不会设置开机自启。

启动失败时窗口会保留原因，日志位于 `.local/server.log`。端口被其他程序或旧版服务占用时会提示处理，不会强行结束进程或换端口。后台服务会在电脑重启后停止，届时再次双击启动。需要手动停止时，可用 `lsof -nP -iTCP:4173 -sTCP:LISTEN` 找到 PID，再用 `ps -p PID -o command=` 确认是本项目的 `scripts/serve.mjs`，最后执行 `kill PID`；不要结束不认识的进程。

开发时仍可在项目根目录运行：

```sh
npm test
npm start
```

打开 http://127.0.0.1:4173 。服务只在进程运行时可用。正式入口是首页，工程诊断入口是 `/public/diagnostics.html`。

`npm run schema` 重新导出配置 schema。`docs/examples` 中的配置是不可播放的结构夹具，不能作为声音方案直接使用。

## 当前能力

- 新增可选的「声音对照模拟」检查页，入口在使用说明的高级检查中。27 组同载体、同 RMS 节律条件验证实际声音输出；另验证自然声混合与双耳声道。它不模拟脑电，不代表已证明人体效果或排除安慰剂。
- 编辑器与播放器根据实际节律目标、增益、深度和静音状态提示是否存在节律输出；目标关闭时不把剩余背景声描述为仍有节律。
- 新增绵雨与水幕两种连续双声道载体，分别用于专注、放松和睡前。载体经过录音纹理重构、宽频段音色匹配和循环接缝处理；独立粉红噪声保持原生成器与未滤波频谱。详情可预听原混音。
- 原自然录音默认单独播放；绵雨入夜未设置偏好时也默认单独声床。需要时可开启混合；已有模式偏好和保存的组合不被覆盖。
- 学习与安静休息已改为绵雨声床的 200–1000 Hz 频段调制，16 Hz 节律集中于中低频；保留两轮学习／静音休息。参考调制音乐论文的频段设计，不将自然声变体宣称为相同功效。
- 新内置白噪声默认比例由 35% 调至 10%，三种纯噪声方案的实测起始 RMS 差不超过 0.61 dB；旧个人组合不变，不进行播放中的自动增益。
- 新内置棕噪声采用 noise-v2 采样率能量补偿；旧组合仍使用原版本。44.1／48／96 kHz 实测能量差约 0.18 dB，48 kHz 与旧算法输出一致。

- 真实雨声、溪流与林间风声录音；三类自然方案可选纯自然声或轻柔噪声混合，支持 1.8 秒循环交叉淡化。录音随应用本地提供，作者、许可及修改说明见 `#/credits`。
- 本机生成白／粉红／棕噪声，支持双耳节拍与振幅调制。自然录音也可加入自由组合并保存，与原有组合兼容。
- 预听与正式播放统一协调；暂停冻结计时；站内换页保持会话；同一浏览器内多个页面不会同时占用播放权。
- 自由组合可定时或持续播放，支持新建、修改、另存副本和直接播放。
- 12 个单阶段内置方案可进入「调整并保存搭配」，修改名称、时长和比例；保存完整声音快照，保留声源版本、节律和渐弱。多阶段学习方案继续以完整流程使用，不压平转换。
- 主音量、低亮显示、方案时长和自然声模式会在本机保留；恢复设置不自动播放，静音值可恢复，偏好存储失败不阻断播放。
- 收藏与最多 50 个个人组合保存在当前浏览器。刷新后恢复；多个页面编辑同一组合时防止旧版本覆盖；删除后可在本次页面会话中撤销最近一次删除。
- 支持查看、全选复制原始 JSON 备份；文件下载入口仍需在常用浏览器确认，当前验收环境未返回下载事件。支持选择 JSON 文件或粘贴备份，预览后合并恢复；保留已有版本，自动跳过重复内容。

目前不包含音乐素材、完整多阶段编辑器、账户、云同步和离线安装包。编辑中的未保存草稿只保留在当前页面会话。当前范围为桌面端应用；手机锁屏与移动端适配不纳入本轮开发。
