# 对照模拟与效果验证

日期：2026-10-28

本轮已经验证应用生成的声音确实包含设定的声学刺激。尚未验证用户的注意、记忆或睡眠改善，也不能排除期待效应。不能用更复杂的脑模型或人为设定的响应曲线补上这段证据。

## 三层证据分别记录

| 层级 | 要回答的问题 | 本轮状态 |
|---|---|---|
| 声音输出 | 自然载体中是否还存在目标节律 是否只是音量变化 | 同载体、同 RMS 控制已完成 |
| 生理响应 | 是否引起预期的神经响应 | 未测量 EEG 不作推断 |
| 实际获益 | 是否改善任务表现或睡眠 是否超出期待和练习因素 | 未开展真人随机对照 |

即便测到脑电同步，也不能直接推出注意或睡眠获益。本轮不增加日常问卷、用户效果打分或遥测。

## 文献如何约束实现

- Woods 等 2024 的调制音乐研究包含无调制及不同调制频率条件，使用 200–1000 Hz 调制频段。应用借鉴频段与对照设计，载体已换成绵雨，因此属于新的实现，不能继承原实验效果结论。[原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC11499863/)
- Nigg 等 2024 的白／粉红噪声荟萃分析主要涉及注意困难人群，且以白噪声研究为主；纳入研究的盲法存在限制。这不支持所有使用者、所有颜色噪声或任意混合比例都有同样收益。[原文](https://pubmed.ncbi.nlm.nih.gov/38428577/)
- Ingendoh 等 2023 对双耳节拍与脑电同步的综述结果不一致。因此应用只说明左右频差及耳机条件，不声称设置 10 Hz 就能进入某种脑状态。[原文](https://pubmed.ncbi.nlm.nih.gov/37205669/)

## 本轮对照模拟

直接调用与 AudioWorklet 共用的生产 `Renderer`，读取实际本地载体文件并核验 SHA-256。没有另造一个理想正弦信号来代替应用输出。

### 调制条件

27 组条件 = 44.1／48／96 kHz × 录音起点 0／10／30 秒 × 无调制／8 Hz／16 Hz。每组渲染 24 秒，分析第 3–23 秒。每对条件保留相同载体、起点、声源增益和调制深度，仅改变是否调制及调制频率。8 Hz 是频率对照，不能假定为生理惰性的安慰剂。

分析前将立体声整体 RMS 统一到 −24 dBFS，排除整体能量差对比较的影响。数字 RMS 不是耳边声压，也不等于主观等响。应用播放不增加自动增益。

对左声道提取 200–1000 Hz 解析包络，再去掉首尾各 1 秒。报告指定频率的包络分量幅度／包络均值，并检查 1–30 Hz 的最大分量。该指标无量纲，不能解读为改善比例，也不是配置中的 40% 深度。

| 检查 | 实测结果 | 能得出的结论 |
|---|---|---|
| 16 Hz 条件的 16 Hz 分量 | 0.244–0.254 | 目标节律存在于输出包络 |
| 无调制／8 Hz 条件的 16 Hz 分量 | 最大 0.018 | 目标分量不是载体自身起伏造成 |
| 每对条件 RMS 差 | 小于 0.000001 dB | 结果不能仅由整体能量差解释 |
| 所有有调制条件的包络峰值频率 | 与设置的 8／16 Hz 一致 | 频率设置实际执行 |

工程断言要求 16 Hz 分量 >0.15 且超过两个对照的 5 倍。这些阈值用于检测实现回归，不是生理有效阈值。有限片段和采样率检查不能代表所有设备或全部播放时间。

### 混合与双耳条件

另外渲染 7 组条件，总计 34 组生产引擎输出。

- 绵雨专注与水幕休息各比较混合、仅载体、仅噪声。混合输出与两个分量相加的最大绝对误差均小于 1e-7。独立噪声相对载体 RMS 分别为 −9.89／−9.07 dB。只能确认噪声没有被程序丢掉，不能由比例推出认知效果或未被听觉掩蔽。
- 双耳方案左侧 195 Hz、右侧 205 Hz 的目标载波与串入另一载波的幅度比均超过 40 dB。将左右声道平均后复制到两耳，左右差异按定义变为零；仍保留两个载波，可能产生单耳拍频。此项是软件下混检查，不是实体耳机串音测量。
- 全部原始输出与分析归一化输出均无数字削波。主观听感本轮未作判断。

### 期待效应示例

另附一个明确假设的统计示例：20 个独立高斯配对差、已知标准差 1、双侧 5% z 检验、固定种子、重复 20000 次。纯零效应的显著比例约 4.8%；加入 0.25 的期待偏移后约 19.6%。把相同偏移改称特异效应会得到完全相同的分布。

这些数值不是实验参与者结果、产品效果估计、文献效应量或样本量建议。示例仅说明：从没有控制期待的改善数据中，无法区分两种解释。

## 真正验证实际效果的下一步

建议先验证一个明确问题：在预先定义的人群中，绵雨上的 16 Hz 调制是否比同一段无调制绵雨改善持续注意。自然声是否优于安静是另一个问题，应使用独立比较，不能混为一谈。

| 步骤 | 执行内容 | 通过条件 |
|---|---|---|
| 1 固定待测版本 | 冻结音频引擎、素材、节律深度、时长、输出设备及校准方式 | 版本和音频指纹可追溯 |
| 2 预注册 | 固定目标人群、主要终点、最小有意义差异、排除规则及分析模型 | 采集数据前确定 不根据结果挑频率或人群 |
| 3 对照材料 | 同载体无调制与 16 Hz 等能量比较 可另加 8 Hz 主动频率对照 | 使用中性编码和相同说明 记录音量与主观响度差异 |
| 4 随机交叉 | 随机且平衡条件顺序 统一练习 时段 任务版本和休息安排 | 建模顺序、练习、疲劳和可能残留效应 |
| 5 主要终点 | 预先选定持续注意任务的 d′ 并预定义极端命中率修正 | 同时检查反应时间与速度准确率权衡 次要终点单独报告 |
| 6 期待与盲法 | 中性介绍 条件编码 数据分析盲态 研究流程中检查条件识别与期待 | 不把隐藏标签叫作成功双盲 报告可听差异带来的限制 |
| 7 样本量与分析 | 用独立先导数据估计个体内差异方差 根据最小有意义差异估算样本量 | 报告效应区间 多重比较与缺失处理 不把声学样本数量当成人数 |
| 8 独立重复 | 在新参与者中按冻结方案重复 | 主要结果可重复 且不依赖主观喜欢程度或单次显著性 |

这是待执行的研究方案，不是已经完成的试验。研究应在独立、自愿参与的流程中开展，按适用要求完成伦理审查与知情同意；不把日常使用者自动纳入研究。

睡眠与放松需另立问题及终点。注意任务的结果不能外推到睡眠；睡眠研究应使用相应客观指标及觉醒／睡眠结构检查，不能仅凭自评或脑电某频段增强判定受益。当前不据此提高睡眠噪声音量或新增整夜刺激。

## 复现与产物

在项目根目录运行，分析脚本需要 Python 3 与 NumPy；应用运行本身不依赖 Python。

```sh
node scripts/simulate-controls.mjs
python3 scripts/analyze-controls.py
node --test tests/*.test.js
```

中间浮点音频写入 `/tmp/wave-controlled-simulation`。输出在 `docs/verification/controls-2026-10-28/`，包含 `results.json`、三段 20 秒同 RMS 对照 WAV 及浏览器截图。WAV 加了首尾 500 ms 渐变并重新匹配 RMS，未作为真人试验刺激完成校准。页面由分析脚本生成到 `public/sound-verification.html`。

回归检查核对音频核心、方案、目录及所用素材的 SHA-256；这些源改变后须重跑模拟以更新结果。页面是有日期的验证快照，不是播放中的实时检测器。
