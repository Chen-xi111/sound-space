# 第 5 步：页面与交互设计

版本：0.2 · 更新：2026-10-08。

状态：首页、方案库、详情、播放页、自由组合、我的方案、使用说明已实现主要流程。采用少量颜色、常规按钮和表单；研究依据收进折叠详情，不增加效果问卷或反馈任务。本文保留完整设计目标，尚未实现的扩展以以下状态为准。

| 已实现 | 后续待做 |
|---|---|
| 六场景入口、搜索与设备筛选、7 个声音方案 | 授权自然录音与音乐、扩充正式方案库 |
| 10 秒预听、主会话协调、阶段播放与进度、低亮显示 | 桌面音频中断与恢复验收 |
| 最多四层的单阶段组合、定时／持续播放 | 完整多阶段编辑器与更细的声音调节 |
| 收藏、保存、修改、另存、删除撤销、JSON 备份文本 | 导入恢复、使用历史、持久偏好与草稿 |

当前导航统一为顶部“发现声音／自由组合／我的方案／使用说明”，窄窗口采用同一简洁导航和单列内容。编辑器地址为 `#/editor`。引擎诊断页独立保留，见使用说明的高级折叠区。

## 1. 体验目标与设计边界

用户先表达“现在想做什么”，再挑选声音。普通使用不需要理解频率、噪声功率谱或 JSON。高级参数与研究来源放在可展开区域，仍然可查、可调整。首次进入不播放声音，不要求注册或测验。

界面工作名暂用“声音空间”，后续统一替换不影响方案身份。中文为主，技术详情保留 Binaural Beats、AM 等英文名称。使用现有柔和米白与深绿方向，重点突出声音组成、时长和当前状态；不做持续闪烁或模拟“脑波检测”的动画。

目前使用 7 个可播放的合成声音方案，相关方向的研究链接可在详情展开。时长、比例与安排明确属于产品设置；授权素材仍在第 6 步补充，不把工程测试音包装成自然录音。TMR、CLAS、40 Hz 不出现在首版普通播放入口中。

## 2. 页面结构与导航

| 页面 | 用户问题 | 首屏信息 | 主要动作 |
|---|---|---|---|
| 首页 | 我现在适合选什么？ | 六场景入口、可用方案、最近使用／收藏 | 选择场景、打开方案、自由组合 |
| 方案库 | 哪个组合适合这次使用？ | 场景、声音类型、时长、耳机条件；名称搜索 | 筛选、详情、预听 |
| 方案详情 | 会听到什么、多久、需要什么设备？ | 名称、组成、时长与阶段、耳机要求 | 开始、预听、调整组合 |
| 播放页 | 正在进行到哪里？ | 状态、当前阶段、已用／剩余时间、总时长 | 暂停／继续、停止、音量、声音比例 |
| 组合编辑器 | 怎么搭配、怎么安排时间？ | 声音层、节律、阶段与结束方式、未保存提示 | 添加层、调整、预听、保存副本 |
| 我的方案 | 如何重复使用自己的组合？ | 个人方案、收藏、最近使用 | 打开、重命名、复制、导入导出 |
| 设置与说明 | 如何管理偏好和本地数据？ | 播放偏好、数据管理、声音来源、兼容说明 | 修改偏好、导出备份、清理 |

桌面使用顶部四项导航，编辑器与摘要并列；窄窗口使用顶部同一导航和单列内容，详情与编辑器占整页。

播放会话由页面之外的应用协调层持有。站内换页保持播放，底部迷你播放器可返回播放页；真正刷新／离开网站遵循当前引擎停止规则。不会因为渲染组件卸载而无意重建音频。

建议先采用静态服务兼容的 hash 路由：`#/home`、`#/library?scene=focus`、`#/recipe/<id>`、`#/player`、`#/editor/<draftId>`、`#/mine`、`#/settings`。路由只定位界面，访问地址不会启动播放。诊断页与产品入口分别保留可访问路径。

## 3. 首页与方案卡片

六个场景按“专注、学习、放松、休息、睡前／睡眠、自由组合”排序。选中场景只过滤方案，不改变播放中的声音。自由组合进入空白草稿；零声音层时可编辑但不可播放或保存为完整方案。

每张卡片包含：

- 方案名称与一句使用描述，例如“阅读时的均匀背景”。用途描述不写成效果保证。
- 明确声音组成，例如“粉红噪声 · 无节律”，而不是仅用色块表示。
- 时长或“持续播放”，有阶段时显示“学习＋休息 · 2 轮”。
- 双耳方案显示“需要立体声耳机”；其他方案不无差别附加耳机门槛。
- 主动作“查看方案”，次动作“预听”；收藏要在第 8 步存储接通后才作为可用功能。

首次访问的“最近使用”和“收藏”使用明确空状态，提供浏览入口；不伪造使用记录、评分、用户人数或推荐理由。第 8 步前尚未实现的区域直接省略，不放没有效果的按钮。

## 4. 方案详情与开始流程

详情显示声音组成、完整总时长、阶段顺序、结束方式、设备条件。调节时长后即时重算摘要。有限／持续必须显式选择；睡前默认有限、无提示音，持续方案明确“直到手动停止”。

主动作“开始”按以下顺序执行：

1. 检查草稿／方案可播放性、设备接口与所需素材。
2. 若同页面有活动会话，显示当前名称，提供“保留当前”和“停止当前并开始新方案”；不直接叠加或悄悄停止。
3. 若播放权在其他页面，提示“另一个页面正在播放，请先在那里停止”，提供重试，不夺取播放权。
4. 显示“正在准备”，禁止重复启动，保留取消按钮。
5. 全部资源准备成功后进入播放页；失败保留选择和参数，显示可执行的修复入口。

来源折叠区说明声音类型的研究方向及应用设置边界；正式首页不展示工程预设标签，未补齐的来源不生成虚构引用。

## 5. 播放页与状态

主区显示当前阶段名称、已用／剩余时间、全流程总时长；持续播放显示累计时长与“持续播放”，不显示虚构倒计时。休息阶段即使全静音，时间仍前进，文字明确“安静休息中”。

| 状态 | 用户看到的内容 | 可用操作 |
|---|---|---|
| 尚未开始 | 方案摘要和时长 | 开始、编辑、返回 |
| 正在准备 | 正在准备声音 | 取消 |
| 播放中 | 当前阶段、计时、音量 | 暂停、停止、当前层音量、跳过／延长 |
| 正在暂停／恢复／停止 | 对应过渡状态 | 禁止重复操作；准备恢复可取消 |
| 已暂停 | 剩余时间保持，提示“等待继续” | 继续、停止、浏览其他方案 |
| 播放中断 | 说明原因，提示时间继续流逝 | 继续前重算位置、停止 |
| 已完成 | 完整进度和“流程已结束” | 再播一次、返回、保存为个人方案（存储接通后） |
| 无法播放 | 原因与修复动作 | 重试、修改方案、返回 |

主音量是设备偏好；层音量是组合比例。现场调整只影响本次会话，已保存方案不会立即变化。显示“本次已调整”，后续用户可主动保存。

“跳过”针对当前这一轮的阶段；“延长”只增加当前实例时长，不改变未来循环。界面立即依据引擎回传更新总时长。最后阶段跳过后结束；不播放自然完成提示。停止后明确“已停止”，不伪装成完整完成。

睡前低亮模式只简化页面、降低界面亮度和动画，不操作系统亮度，不要求屏幕常亮，不将低亮模式表述为已支持锁屏播放。

## 6. 预听协调：必须先补齐的接入点

现已实现产品级“正式会话＋预听”协调器 `src/product/session.js`，统一管理生命周期和跨标签互斥。卡片使用同一协调器。

预听长度建议 10 秒，是产品默认值，不是研究刺激时长。采用真实方案的首个有声音阶段，明确显示“预听片段”；没有可发声阶段时禁用预听并说明原因。预听不覆盖完整流程、不计入正式使用记录。

无活动会话时：用户点击预听 → 独占短会话 → 到期释放。

已有正式会话时：先通过用户动作“暂停当前并预听”确认处理 → 调用并等待正式会话暂停完成 → 预听获取播放权。预听结束或手动停止后，原会话保持暂停；界面提供“继续原方案”，不会自动恢复声音。

协调器只持有一个正式会话和至多一个预听对象，任何时刻至多一个有输出。停止、换页、预听失败和播放权被另一标签占用，都必须释放预听资源并保留原暂停状态。不能把中断中的原会话误转换为手动暂停来冻结它的截止时间。

## 7. 编辑器的三组设置

### 声音层

最多四层，列表逐项显示名字、类型、音量、静音、删除。添加第五层时说明上限并要求先移除；不自动替换。自然声／音乐仅列出真实已授权、可加载的素材。素材尚未接入时显示“素材库待加入”，不提供假播放。

噪声高级项：颜色、滤波、声像；节律层高级项：左右载波、频差和设备条件。种子等复现信息放在来源／高级详情，不让普通用户必须填写。

### 节律

用互斥选项“无／双耳节拍／振幅调制”。切换种类前说明被替换的内容；不能通过阶段编辑绕过单节律约束。AM 必须选定目标层，目标删除前先移除或改绑 AM。

### 时间安排

有限／持续、阶段名称与时长、淡入淡出、循环次数、结束提示。阶段里始终有完整的层状态；删除一个全局层时同步清理所有阶段引用。持续模式只保留一个阶段，切换前展示将丢弃的阶段安排并允许取消。

本步先完成编辑页面与输入反馈；完整阶段增删／排序、执行调整的另存转换在第 7 步接通。本步不放可点击但无效果的“保存”或“导出”。

编辑中的结构变化不改正在播放的快照，显示“下次开始时应用”。即时层音量调整只在播放页执行，并与编辑草稿分开，避免用户误以为保存草稿改变了本次声音。

## 8. 保存、恢复与错误文案

持久化在第 8 步实现，界面提前遵守以下契约：

| 情况 | 文案／行为 |
|---|---|
| 修改内置方案 | 保存个人副本，不覆盖内置原件 |
| 草稿未保存离开 | 保存并离开／放弃修改／继续编辑；保存失败留在原页 |
| 本地存储失败 | “未能保存，修改仍保留在当前页面”，提供重试／导出路径 |
| 另一页面已更新方案 | 提供另存副本或查看新版，不无声覆盖 |
| 缺少素材 | 指明缺哪一层；补齐或明确移除后才可开始 |
| 参数越界 | 错误紧邻字段，显示允许范围；不静默截断数值 |
| 错误文件／未知版本 | 阻止播放，保留原文件与当前草稿 |
| 加载历史或导入成功 | 显示配置；仍需主动点击开始 |
| 删除个人方案 | 支持撤销或明确确认；不销毁已经开始的播放快照 |

页面主区使用可理解的中文。错误代码、素材版本、配置详情可在“详细信息”展开，普通播放流程不展示 JSON。

## 9. 视觉与可访问性规格

- 字体：系统中文无衬线；正文 16 px，辅助文字不低于 12 px；计时数字使用等宽数字。
- 页面：米白背景、深绿文字与主按钮、浅绿状态区；中断和错误另用文字说明，不能只变色。
- 间距按 4／8 px 梯度，卡片内边距 20—24 px；触摸目标至少 44×44 px。
- ≥1024 px 使用双栏详情／编辑；768—1023 px 缩减侧栏；<768 px 单列。验证 390、768、1280 px 实际尺寸，不能只检查 CSS 存在。
- 所有按钮与表单有可读名称；选择器和对话框支持键盘，弹窗关闭回到原触发位置。
- 状态变化使用温和的读屏提示；每秒进度刷新不反复播报。错误提示能定位对应字段。
- 遵从减少动态效果偏好；装饰动画不承载时间或播放状态，也不影响音频调度。
- 主按钮、正文、禁用状态在明暗主题分别检查对比度；低亮模式仍能辨认暂停与停止。

## 10. 接入结构与实现顺序

保持无第三方依赖的当前项目结构，先复用现有 ES modules；没有实际需要时不引入构建框架。以下是待实现的职责划分，不表示已有文件：

| 模块 | 责任 | 依赖 |
|---|---|---|
| 应用壳与路由 | 导航、迷你播放器、焦点和页面状态 | 现有静态服务 |
| 方案目录适配 | 场景筛选、详情摘要、可播放性、来源标签 | schema 与 validate；第 6 步替换正式目录 |
| 会话协调器 | 正式会话、预听、替换确认、独占播放 | AudioEngine 与 PlaybackOwnership |
| 播放视图 | 人类可读阶段名、进度、暂停／中断区别、音量 | 引擎事件与会话快照 |
| 编辑草稿 | 输入与字段错误、与会话隔离 | validate 与第 3 步契约 |
| 本地方案适配 | 保存、导入导出、修订冲突、偏好 | 第 8 步实现 |

执行顺序：

1. 5A：产品入口、导航、六场景、开发方案卡片与详情；诊断页保留独立入口。
2. 5B：详情开始→真实播放页→暂停／继续／结束，接入迷你播放器。所有播放按钮共用协调器。
3. 5C：短时预听、暂停后预听、预听结束后手动恢复；处理跨标签占用与资源失败。
4. 5D：声音组合表单与错误反馈、草稿状态；阶段编辑和保存功能按后续步骤逐项开放。
5. 5E：键盘、390／768／1280 px、重复点击、站内切页和中断状态回归，保存真实截图与记录。
6. 第 6 步填充正式内容；第 7、8 步分别完成阶段编辑与持久化，再做第 9 步完整交付验收。

## 11. 第 5 步完成标准

| 编号 | 可观察结果 |
|---|---|
| UI-01 | 六个入口可导航，筛选结果正确，空结果可清除筛选 |
| UI-02 | 方案详情明确组成、时长、设备条件，点击开始才能出声 |
| UI-03 | 播放状态与引擎一致；暂停冻结、正常结束／中断到期显示完整进度 |
| UI-04 | 站内切页不重建会话，迷你播放器可返回；外部刷新后不自动播放 |
| UI-05 | 预听不叠加正式声音，结束后原会话仍暂停，跨标签占用可理解 |
| UI-06 | 不支持接口、素材失败、非法参数等状态有明确反馈和恢复入口 |
| UI-07 | 窄窗口主要按钮可触达，无横向溢出；桌面布局和键盘操作实测 |
| UI-08 | 工程预设与正式内容标记清楚，不显示假素材、虚构来源或无效保存成功 |

UI-01—08 目前仍待实现与验证。本机浏览器的第 4 步核心验收通过不等于第 5 步用户流程完成，也不等于手机锁屏可用。下一次可直接从 5A 开始实施，无需重新做科研综述或推翻数据模型。
