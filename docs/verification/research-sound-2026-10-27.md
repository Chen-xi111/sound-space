# 文献与声音实现验收

完成日期 2026-10-27 Europe/London。沿用本地工作区与原站点地址，没有发布或更改现有用户库。前置基线 168 项，本轮 181 项自动检查全部通过。

## 实现与自动检查

- 学习流程采用绵雨、band-am-v1、200–1000 Hz、16 Hz。原全频 AM 路径保留
- 44.1／48／96 kHz 测试音边带位置、对称性、带外衰减、左右声道隔离通过
- 零深度等于原声，暂停冻结、静音阶段无滤波残响、主音量 0 输出全零
- 预听保留原声音来源与节律；只截短时间和淡入淡出
- 未知处理器、无效频段和不支持采样率拒绝播放
- 新内置白噪声固定增益降至 0.1；三个采样率下纯噪声默认输出差均小于 1 dB，旧白噪声组合比例不变，实时调节不被归一化覆盖
- 新版棕噪声能量稳定；48 kHz 与旧版逐样本一致；旧算法仍可用
- 新处理器个人快照与旧自由组合共同保存、重开、备份恢复通过。使用内存存储夹具，未向用户库注入测试组合
- 睡前纯声床默认、明确选择的旧混合、长结束渐弱与个人快照兼容通过
- 新导出 schema 与配置检查通过。应用依然无新增运行依赖

原始测试输出见 [node-tests.tap](node-tests.tap)。

## 实际输出

使用生产 DSP 渲染，非另写的声音模拟器。结果见 [measurements.json](research-sound/measurements.json)。

| 核查 | 结果 |
|---|---|
| 白／粉红／棕频谱斜率 | 分别接近 0／−3／−6 dB 每倍频程，覆盖 44.1／48／96 kHz |
| 棕噪声采样率能量差 | 新版三个采样率最大差 0.181 dB；旧版 96 kHz 高于 48 kHz 2.840 dB |
| 新声床实际分析包络 | 16 Hz 分量／包络均值 0.251，相邻测试频率最大 0.0123 |
| 新声床循环 | 45 秒进入交叉淡化、46.8 秒回跳的样本差分别约 0.00660／0.00750，低于正常纹理跳变的 99.99 百分位 0.03069 |
| 新声床峰值与削波 | 60 秒、48 kHz、主音量 100% 下峰值 0.07730，零削波 |
| 对比试听 | 同一绵雨载体的原声、全频调制、频段调制各 20 秒，统一 RMS −24 dBFS；没有在运行时自动抬高音量 |

## 范围与剩余

本轮通过的是声学参数和软件行为验收。未做真人听感评审、声压校准、听力测量或新的注意／睡眠疗效试验。滤波器是平滑频段处理，不代表绝对带外零调制。自然声变体不等于论文音乐。

本轮不改变手机锁屏范围，不新增云服务、账户或遥测，不新建日程。计划中的草稿恢复、多阶段编辑和安装包仍待后续；自然载体的主观听感留待实际试听。
