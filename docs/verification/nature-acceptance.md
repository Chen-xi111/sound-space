# 自然声音接入与验收

日期：2026-10-09

## 本轮实现

- 3 段开放许可的真实自然录音：雨声（ezwa）、溪流（Siddharth Patil）、林间风声（luc de bruijn）。来源、处理过程、许可和 SHA-256 见 `public/assets/SOURCE.md` 与 `nature-manifest.json`。
- 3 个新方案：雨中专注 25 分钟、溪边小憩 10 分钟、林间入夜 30 分钟。各可选纯自然声或轻柔背景噪声；自然声与噪声为独立声源，不将其称作“隐藏脑波”或原研究的等效刺激。
- 方案开始 2.5 秒渐入；一般结束 3 秒渐弱；睡前最后最多 5 分钟渐弱。1 分钟等短时长也保证进出包络总长不超过阶段。
- 录音以 1.8 秒交叉淡化循环。素材时长 30 / 28 / 45 秒；循环周期分别为 28.2 / 26.2 / 43.2 秒。循环重叠使用现有线性交叉淡化，不宣称重复完全不可察觉。
- 首次总音量仍为 20%，不会自动播放。自然方案录音层默认增益 0.8，粉红背景 0.08、棕背景 0.04。百分比是增益而不是感知响度或功效强度。
- 自由组合可以混合自然录音、三类噪声与可选节律，保持最多四层。AM 的目标仍是第一层；双耳载波保持独立声道。
- 自然组合以素材 ID 和 revision 保存；原有纯噪声组合不迁移、不覆盖。未知素材版本会阻止保存／播放，不静默改用其他声音。
- 首页三张自然方案卡片及雨声快捷开始；播放页默认收起分层调整，保留总音量。独立 `#/credits` 提供署名、许可证链接、修改说明。理念页和使用说明同步当前能力。
- 录音均为本地 WAV，总计约 7.1 MB；运行时无外部素材请求。保留现有文件大小、哈希、时长、声道和解码内存检查。加载失败给出可重试提示，不退回合成噪声。
