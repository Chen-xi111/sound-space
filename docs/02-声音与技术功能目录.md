# 声音与技术功能目录

版本：0.2 · 更新日期：2026-10-06 · 状态：经设计审查修订；配套数据契约见第 3 步文档

本文完成 workflow 第 2 步，与 [首版产品需求文档](01-首版产品需求文档.md) 配套。功能依据来自本次对话已经整理的研究，不新增科研复现或功效验证任务。

本文列出需要表达和实现的参数，不在本阶段锁定最佳频率、音量或疗程。参数的具体初值和可调边界在第 4、6 步完成；已有研究方法可直接作为方案参数来源。

## 1. 统一分类方式

把平台能力分成三个层次，避免将噪声颜色、脑波名称和播放协议混成同一种音轨。

| 层次 | 表达什么 | 例子 |
|---|---|---|
| 声音来源 | 实际产生或播放什么声音 | 粉红噪声、雨声、音乐、纯音 |
| 节律处理 | 如何组织或调制声音 | 双耳频差、振幅调制 |
| 播放协议 | 何时、在什么条件下播放 | 定时阶段、TMR 提示队列、CLAS 相位触发 |

统一的模块目录如下。首版需要六类能力，而不是六套互不兼容的播放器。

| 技术 ID | 类型 | 软件模块 | 首版归属 | 主要场景 | 依赖 |
|---|---|---|---|---|---|
| TECH-01 | 白／粉红噪声 | 噪声生成器 | V1 | 专注、学习、自由组合 | 音频核心 |
| TECH-02 | 棕噪声 | 噪声生成器的独立类型 | V1 | 背景声、自由组合 | 音频核心 |
| TECH-03 | 自然声 | 素材播放与循环模块 | V1 | 放松、休息、睡前、背景声 | 素材目录与授权记录 |
| TECH-04 | 轻音乐／睡前音乐 | 音乐素材播放模块 | V1 | 放松、睡前、可选工作背景 | 素材目录与授权记录 |
| TECH-05 | 双耳节拍 | 左右声道纯音模块 | V1 高级功能 | 用户自选节律方案 | 立体声输出与耳机条件 |
| TECH-06 | 振幅调制声音／音乐 | 指定音轨的调制模块 | V1 高级功能 | 持续工作、学习、自由组合 | 可调制的声音层 |
| TECH-07 | TMR | 学习内容与提示队列协议 | V2 | 已学内容的提示重放 | 内容绑定、触发与暂停规则 |
| TECH-08 | CLAS | EEG 驱动的事件刺激协议 | V3 | 睡眠慢波相位相关声音刺激 | 实时 EEG、相位估计、时序控制 |
| TECH-09 | 40 Hz 感官刺激 | 独立节律协议／声光同步模块 | V2 音频、V3 声光 | 独立高级模块 | 精确节律；视觉版本另需显示时序能力 |

## 2. 首版组合规则

| 规则 ID | 规则 | 实现含义 |
|---|---|---|
| MIX-01 | 每方案最多四个声音层 | 双耳节拍的一对左右声道合计一层；振幅调制是处理器，不额外占层 |
| MIX-02 | 全方案最多一个主要节律实例 | 最多一个双耳节拍层，或一个振幅调制处理器；两者互斥，静音的层也计入限制 |
| MIX-03 | 一个振幅调制处理器对应一个目标层 | 避免无意调制整个混音；目标层移除时同步移除或重新指定处理器 |
| MIX-04 | 背景声可以组合 | 噪声、自然声、音乐受四层限制及总输出管理约束 |
| MIX-05 | 双耳节拍保持声道独立 | 左右信号不因声像、单声道混音或空间效果被意外合并 |
| MIX-06 | 同一时间只有一个播放所有者 | 正式播放、预听和其他标签页共用排他控制；预听结束不自动恢复正式会话 |
| MIX-07 | 阶段切换平滑 | 音量、参数与素材过渡经调度器统一处理 |
| MIX-08 | 专用协议不作为普通拖拽音轨 | TMR、CLAS、40 Hz 感官模块后续使用独立入口和触发逻辑 |
| MIX-09 | 静音也是有效阶段 | 休息阶段可以无声音，计时与流程仍正常运行 |
| MIX-10 | 首版节律类型在方案内保持一致 | 可按阶段改变数值或启停，但不在双耳节拍与振幅调制之间自动切换 |
| MIX-11 | 四层是全方案来源池上限 | 各阶段启停同一来源池，不通过阶段追加隐藏的第五层 |
| MIX-12 | 每阶段保存完整状态 | 每层均有明确启用、增益和参数；静音、跳过、循环不会继承前一阶段临时设置 |

示例：粉红噪声＋雨声＋双耳节拍占三层；音乐＋雨声并对音乐施加振幅调制占两层。以上是结构示例，不是已验证的联合功效方案。

## 3. 参数记录原则

每个参数都要能区分来源：研究方法给定值、产品默认值、用户自定义值。平台记录实际数值与单位，频段名称作为辅助标签。

| 参数类别 | 记录与显示原则 |
|---|---|
| 频率 | 使用 Hz；区分声音载波、双耳频差、调制速率、设备检测的脑电相位 |
| 时间 | 使用明确的秒／分钟／毫秒；脉冲长度与重复频率分别记录 |
| 音量 | 内部使用数字增益，界面可用百分比；不当作用户耳边实际 dBA |
| 调制深度 | 内部使用统一范围，界面使用百分比；与声音主音量分开 |
| 脑波标签 | theta、alpha、beta 等是节律分类名称，不代替参数与使用条件 |
| 素材版本 | 使用稳定的素材标识与版本，保存来源和授权条件 |
| 方案版本 | 保存所采用的配置；来源方案更新不改写个人副本 |

## 4. TECH-01：白／粉红噪声

**模块定位：**可持续生成的基础声音来源。白噪声与粉红噪声是两种可选频谱类型，共用噪声生成模块。

**首版操作：**选择类型、调整层音量、静音、移除；高级区可调整音色滤波。作为基础层参与专注、学习和自由组合，也可由用户选入其他场景。

| 参数 | 单位／类型 | 说明 |
|---|---|---|
| 噪声类型 | white / pink | 必填，不能仅用显示名称区分 |
| 层增益 | 数字增益 | 与主音量独立 |
| 声道模式 | 单声道／立体声策略 | 由引擎与方案明确记录 |
| 滤波配置 | Hz、滤波类型 | 可选；设置后记录为经过滤波的噪声 |
| 随机生成配置 | 算法版本、可选种子 | 第 3—4 步决定复现粒度，不承诺跨实现逐采样一致 |
| 启停包络 | 时间 | 减少开始与停止时的突变 |

**实现完成条件：**频谱类型符合定义；连续播放无素材循环点；音量与滤波变化平滑。研究来源见 REF-01。

## 5. TECH-02：棕噪声

**模块定位：**偏低频的噪声来源，与 TECH-01 共用控制和输出管理，但保留独立类型标识。

**首版操作：**选择棕噪声，调整层音量与可选滤波，参与普通声音组合。

**参数需求：**类型、增益、声道模式、滤波配置、算法版本、启停包络。实现时处理低频能量累积、直流分量与归一化，不因为更换颜色导致不可控音量跳变。

**实现完成条件：**生成稳定，切换顺畅，可保存恢复。作为声音偏好选项，不复用白／粉红噪声研究为其添加独特功效标签。关联研究边界见 REF-01。

## 6. TECH-03：自然声

**模块定位：**可循环的环境音素材。首批优先考虑雨、水流、风等连续性较好的素材；具体文件在第 6 步选择。

| 参数 | 单位／类型 | 说明 |
|---|---|---|
| 素材引用 | ID＋版本 | 关联文件位置与授权信息 |
| 层增益 | 数字增益 | 独立调整 |
| 起始位置 | 秒 | 可选，支持素材内起播 |
| 循环区域 | 起点／终点 | 记录实际边界 |
| 交叉淡化 | 秒 | 消除明显循环接缝 |
| 声像 | 左右位置 | 可选；不影响双耳节拍层的独立声道 |
| 加载状态 | 枚举 | 未加载、加载中、可用、失败 |

**首版操作：**预听、添加、音量调整、静音、移除。切换预听时不与活动会话无管理地叠加。

**实现完成条件：**循环无明显断点，素材缺失可识别，来源和授权可追溯。关联研究见 REF-02。

## 7. TECH-04：轻音乐／睡前音乐

**模块定位：**音乐素材层。首版使用预先准备的合法素材，不接入生成式音乐服务。

**参数需求：**素材 ID／版本、增益、循环或播完停止模式、起始位置、淡入淡出、文件时长、授权条件。素材播完停止仅使该层安静，不提前结束阶段；循环必须有合法边界。标签可记录有无人声、适用场景、声音强度等编辑信息，不直接充当科学功效评分。

**首版操作：**预听、选择、音量调整、与自然声或噪声组合；需要时作为 TECH-06 的目标层。

**实现完成条件：**曲目结束行为明确，过渡不突兀；保存方案只保存引用，不随导出传播音频文件。关联研究见 REF-03。

## 8. TECH-05：双耳节拍

**模块定位：**左右耳分别接收不同频率的纯音。整对声道作为一个声音层，与普通背景层混合。

**设备条件：**立体声耳机及正常的左右声道输出；启用前显示简短说明。不宣称网页可自动判断用户耳机佩戴状态。

| 参数 | 单位／类型 | 说明 |
|---|---|---|
| 中心载波频率 | Hz | 由此计算左右频率，避免多个重复字段互相矛盾 |
| 双耳频差 | Hz | 与载波分开显示 |
| 频段标签 | theta / alpha / beta 等 | 根据实际频差辅助分类，边界约定在后续统一 |
| 左右分配 | 枚举 | 明确高低频如何分配给左右声道 |
| 层增益 | 数字增益 | 独立于背景声与主音量 |
| 参数过渡 | 时间／方式 | 频率变化时平滑衔接 |

**首版操作：**选择节律选项，展开调整载波与频差，控制与背景声的比例。首批界面提供 theta、alpha、beta 选项；具体预设值在第 6 步形成。

**实现完成条件：**左右频率及差值与设置一致；不把声道合并；暂停恢复与阶段切换无明显突变。不能以单声道普通节拍替代并继续标为双耳节拍。关联研究见 REF-04、REF-05。

## 9. TECH-06：振幅调制声音／音乐

**模块定位：**对指定音轨的幅度施加周期性变化。它是声音处理器，不是单独素材，也不是双耳节拍。

| 参数 | 单位／类型 | 说明 |
|---|---|---|
| 目标层 | 声音层引用 | 首版一次只调制一个来源层 |
| 调制速率 | Hz | 描述每秒变化次数 |
| 调制深度 | 比例／百分比 | 与目标层增益分开 |
| 调制波形 | 类型 | 首版优先平滑波形；可扩展其他形状 |
| 强度处理 | 归一化策略 | 控制启停处理前后的响度变化 |
| 参数过渡 | 时间／方式 | 改变频率或深度时平滑处理 |

**首版操作：**选择可调制层，启用调制，调整速率与深度。普通场景可直接使用内置方案，不必理解处理链。

**实现完成条件：**调制只作用于目标层，移除目标层后不会残留悬空处理器；可保存恢复处理关系。关联研究见 REF-06、REF-07。

## 10. TECH-07：目标记忆再激活 TMR

**开发归属：**V2，独立学习模块。首版仅在整体设计中保留扩展方向，不出现不可用的播放按钮。

**工作流程：**学习内容与提示音绑定 → 学习时使用该关联 → 建立提示队列 → 在满足所选协议条件时重放 → 记录实际触发与中断。

**未来参数需求：**学习项目 ID、提示音 ID、关联版本、提示时长、增益、播放间隔、重复次数、队列顺序、允许播放条件、停止条件、触发来源与日志。

**设备与协议条件：**提示音播放本身可以由软件完成；如需按睡眠阶段播放，应接入相应检测来源。单纯定时播放不能在界面中标成已经识别了睡眠阶段。

**进入开发前需确定：**学习内容形式、提示音绑定流程、睡眠阶段来源、用户唤醒或中断时如何停止。与首版学习计时功能分开。关联研究见 REF-08。

## 11. TECH-08：闭环声音刺激 CLAS

**开发归属：**V3，设备扩展模块。普通粉红噪声播放不显示为 CLAS。

**工作流程：**接收实时 EEG → 判断信号可用性及允许刺激状态 → 估计目标慢波相位 → 调度短脉冲 → 记录实际输出时序 → 信号不足或状态不符时停止触发。

**未来参数需求：**设备与通道、采样率、时间戳、信号质量阈值、允许睡眠阶段、目标相位、预测策略、端到端延迟、脉冲类型、脉冲时长、增益、脉冲间隔、暂停规则、实际触发日志。

**设备条件：**能够提供足够及时且可用的脑电数据、可测量的音频输出时序。需评估无线链路和缓冲延迟；普通睡眠分数或心率不能直接代替慢波相位。

**参数来源示例：**前述 MIT 研究使用 50 毫秒粉红噪声脉冲。这一数值是脉冲长度，不是播放总疗程，也不是重复频率；采用时仍需保留该研究的触发条件。关联研究见 REF-09、REF-10、REF-11。

**进入开发前需确定：**设备接口、时间同步方式、相位算法、实际输出延迟与异常暂停流程。MRI 属于研究测量手段，不是预设的用户端必需设备。

## 12. TECH-09：40 Hz 感官刺激

**开发归属：**V2 独立音频模块；如果增加视觉刺激，则进入 V3 声光同步模块。

**概念区分：**40 Hz 声音脉冲／调制、40 Hz 双耳频差、40 Hz 纯音是不同信号；研究中的声光联合条件也不能只用一个“40 Hz”字段表达。

**未来参数需求：**刺激模态、实际波形、载波、重复／调制速率、脉冲长度或占空比、增益、时长、视觉参数、声光相位关系、设备能力与中断规则。

**界面安排：**独立入口与协议说明，不作为首版“防痴呆”按钮，也不自动附加到普通睡眠方案中。

**进入开发前需确定：**具体采用哪种音频方式、是否包含视觉、硬件时序能力和独立使用要求。关联人类研究见 REF-12。

## 13. 软件模块依赖

| 模块 | 首版职责 | 后续可复用点 |
|---|---|---|
| Audio Core | 生命周期、时钟、主输出、增益与中断管理 | 所有协议共用的播放基础 |
| Source Registry | 噪声生成器与素材来源管理 | 新素材、新生成方式 |
| Layer Mixer | 最多四层的增益、静音和路由 | 更复杂的组合 |
| Rhythm Engine | 双耳节拍、单层振幅调制 | 独立节律协议的基础信号能力 |
| Session Scheduler | 定时、阶段、循环、淡入淡出 | 提示队列和事件触发接口 |
| Preset Library | 内置方案、来源、版本与个人副本 | 分享与云同步 |
| Local Preferences | 收藏、隐藏、最近使用、场景偏好 | 跨设备同步 |
| Device Adapter | 首版不实现实时 EEG | TMR 阶段来源、CLAS 实时数据 |

以上是职责划分，不要求创建同名目录或类。第 3 步先定义概念关系，第 4 步再选择实际实现结构。
