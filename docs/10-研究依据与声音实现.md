# 研究依据与声音实现

本轮实现：2026-10-26—27。范围为本地桌面应用的声音输出与默认方案，不开展用户研究或收集问卷。

## 从文献到产品

| 原始研究 | 关键条件与结果 | 本轮落实 | 未直接迁移的部分 |
|---|---|---|---|
| [Nigg 等 2024 · 白／粉红噪声与注意任务](https://pubmed.ncbi.nlm.nih.gov/38428577/) | 13 项研究 335 名 ADHD 或注意困难参与者 平均效应小；非 ADHD 对照平均负效应 | 保留纯噪声选择 核查频谱 不把所有学习场景强制设为噪声 | 不把混合载体或棕噪声标为同等有效 不把数字音量当作实验声压 |

| [Basner 等 2026 · SLEEP](https://pubmed.ncbi.nlm.nih.gov/41627391/) | 25 名成人 7 夜多导睡眠实验；40／50 dBA 连续粉红噪声条件出现 REM 减少 | 绵雨入夜的新默认只播放声床 保留定时与渐弱 不自动整夜续播 | 单独自然声也没有据此获得改善睡眠的证明；不将连续噪声等同于脑电闭环短脉冲刺激 |

这是针对当前改动的文献核对，不是新的系统综述。已有注意、放松与睡眠文献的结果来自不同人群、任务、声音和暴露条件，不能合并成统一的“频率—功效处方”。可选理念页继续提供研究链接，主流程不增加科研反馈。

## 已上线的声音变化

### 学习与安静休息

- 使用现有 `carrier-soft-rain@1` 绵雨素材 不叠加第二条无节律噪声
- 保留原声 并加入其 200–1000 Hz 频段的正弦调制分量
- 保留 25 分钟学习、5 分钟静音、两轮流程与淡入淡出
- 10 秒预听与正式播放使用同一个处理器；预听只缩短时间包络
- 这是参考声学设计的自然声变体 不宣称已证实提高学习表现

### 纯噪声默认比例

原先白／粉红／棕都使用 0.35 层增益，但白噪声自身 RMS 比粉红噪声高约 11 dB。将新内置「均匀背景」白噪声增益改为 0.1，以固定默认值减少切换时的能量落差。44.1／48／96 kHz 的实际 Renderer 输出中，三种纯噪声 RMS 最大差分别为 0.545／0.609／0.530 dB。

测量采用主音量 100%、15 秒输出中的第 3—15 秒。仅调整新内置默认值；保存的旧白噪声比例与用户实时调整保持不变。该校正不改变频谱形状，也不是主观等响或研究声压标定。

### 棕噪声跨设备一致性

测量发现旧生成器在 96 kHz 的输出能量高于 48 kHz 约 2.84 dB。新增 `noise-v2`，按泄漏积分器的稳态方差补偿采样率，以 48 kHz 旧输出为基准。在本轮 12 秒测试样本中，44.1／48／96 kHz 的 RMS 最大差缩小到 0.18 dB。

新内置棕噪声方案使用 v2。旧自由组合和已保存的 v1 快照继续用 v1；48 kHz 下 v1 与 v2 棕噪声逐样本一致。白／粉红算法不变。这里校正数字信号能量，不代表不同耳机或扬声器的实际声压已相同。

### 睡前默认

未设置偏好时，绵雨入夜默认单独声床。已有用户选择的融合模式、保存搭配和时长不被覆盖。保持有限时长与末尾渐弱，无自动播放和自动续播。纯声床仍是声音暴露，并非“无风险”或“已验证助眠”的替代结论。

## 版本与处理契约

`schemaVersion: 1` 增加严格的 AM 结构分支：

```json
{
  "kind": "amplitudeModulation",
  "targetLayerId": "nature",
  "waveform": "sine",
  "processorVersion": "band-am-v1",
  "band": { "lowHz": 200, "highHz": 1000 }
}
```

`band-am-v1` 每声道串联二阶 Butterworth 高通与低通，输出 `y = x + depth × sin(phase) × bandpass(x)`。频段边缘为平滑衰减，不是砖墙截断。depth 是调制注入系数；滤波相位和载体本身使最终包络深度不等于这个参数。默认 0.4 是设计选择。

不含 processorVersion 的旧 AM 继续输出 `x × (1 − depth/2 + depth/2 × sin(phase))`，其相对调制指数为 `depth/(2−depth)`。不能把两个版本的 depth 当成同一量。未知处理器版本、反向频段、超出采样率范围的频段拒绝播放。阶段切换重建滤波状态，暂停冻结状态，静音休息不保留音频尾巴。

新应用兼容旧格式。旧应用可能拒绝新 band-am-v1 或 noise-v2 配置；不会把它们静默降级成旧算法。备份容器仍为 version 1，个人快照保留版本；新增兼容测试覆盖保存、重开和备份恢复。

## 声学验收

见 [原始测量](verification/research-sound/measurements.json) 和 [验收记录](verification/research-sound-2026-10-27.md)。

| 指标 | 本轮结果 |
|---|---|
| 白噪声 100–8000 Hz PSD 斜率 | −0.014 至 +0.015 dB／倍频程 |
| 粉红噪声同频段斜率 | −3.10 至 −3.14 dB／倍频程 |
| 棕噪声同频段斜率 | −5.96 至 −6.04 dB／倍频程 |
| 新声床 200–1000 Hz 分析包络中的 16 Hz 分量／均值 | 0.251 原声约 0.008；相邻 14／15／17／18 Hz 最大约 0.012 |
| 新声床较原声稳定段总 RMS 变化 | +0.103 dB 无自动增益 |
| 新声床 60 秒 48 kHz 渲染 | 零削波 最大样本幅度 0.0773；交叉淡化入口与回跳均非跳变离群值 |

频谱使用 seed 29、预热 1 秒后的 12 秒数据，Hann Welch 8192 点、4096 点步长，32 个对数频带回归。覆盖 44.1／48／96 kHz。实际声床使用生产 Renderer，48 kHz 双声道 60 秒，主音量 100%。数字 dBFS 与 dBA 声压不同。

500 Hz 测试音在两侧 ±16 Hz 出现对称边带；80 Hz、4 kHz 的边带明显较弱，三个采样率均通过。零深度输出与原声逐样本一致。声床自身的 16 Hz 包络也已测量，避免只验证理想测试音。

## 对比与复现

三个样本使用同一绵雨载体，20 秒、双声道 48 kHz、整体 RMS 统一到 −24 dBFS，仅对导出的比较文件归一化，不改变应用音量。宽带样本把旧 depth 设为 4/7，使其相对调制指数为 0.4，与新频段注入系数对应；滤波后的有效包络仍不相同。等 RMS 不代表主观等响。
