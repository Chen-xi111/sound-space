# 第 8 步：本地方案管理（已实现部分）

更新：2026-10-26。

## 用户流程

内置方案可收藏，在首页及“我的方案”复用。自由组合可以保存、新建、修改、另存副本，从“我的方案”直接播放。新建或打开已有方案会保护未保存的修改；站内换页保留编辑区草稿，刷新／关闭时由浏览器提示未保存内容。

删除后显示“撤销删除”，只恢复本次页面会话中最近一次删除。当前没有持久回收站，刷新页面会失去撤销入口。保存中的页面切换不会将旧保存结果写进新草稿。

## 存储与并发

- `src/product/library.js` 管理 `wave-platform.library.v1`，使用 localStorage 保存 `{version:1,favorites:[],saved:[]}`。
- 收藏存方案 ID；个人条目存 ID、修订号、创建／更新时间、编辑器草稿快照。支持自由组合和内置方案的单阶段个人搭配。
- 保存前立即复制并校验草稿，异步写入期间继续编辑不会改变本次提交内容。
- Web Locks 串行化跨页面的读—改—写；与音频播放锁独立。更新与删除需要匹配基础修订号；冲突保留草稿，允许另存副本。
- 数据体积限 150 万字符，最多 50 个组合、200 个收藏。无存储权限、空间不足、未知版本或损坏数据均明确报错，不覆盖原数据。
- 读取时校验声音层 ID、参数及生成的完整配方，包括条目时间与修订信息。禁止任意脚本或外部素材 URL。
- 当前依据 v1 草稿重新构造配方，并非存储完整音频算法快照。未来修改默认算法／构造规则前，必须先设计版本迁移，不能无声改变已有组合。

## 备份与边界

使用说明中可打开原始 JSON 备份、全选复制或尝试下载文件。损坏数据也可原样导出用于修复。2026-10-08 已检查页面提供的备份结构及全选内容；内置浏览器未返回文件下载事件，下载落盘不列为通过。

当前没有云同步、持久草稿、使用历史、批量管理。数据只属于当前浏览器和站点地址，清理浏览器数据会移除；刷新不会自动开始播放。

## 验证

自动检查覆盖重开恢复、保存快照、两页面并发收藏、旧版本冲突、存储失败、损坏数据保留、删除撤销、接口不可用、非法层 ID 和错误元数据。

本机浏览器已实际完成保存→刷新恢复→双页冲突→另存副本→删除→撤销→直接播放，并核对已保存的时长与声音比例。完整证据见 [产品界面验收](verification/product-acceptance.md)。

## 2026-10-09 自然录音扩展

个人组合的声音层新增 `assetRef: {id, revision}`，与原 `color` 噪声字段互斥。只接受内置的自然录音版本，不接受任意 URL。保存、另存、删除撤销、重新打开和快照播放沿用现有流程；原 version 1 纯噪声组合可以直接读取。素材未来升级时保留旧版本映射，不能让旧组合静默切换录音。

方案详情的「纯自然声／混合」选择和时长当前仅在打开的页面会话中记住；长期保存自己的搭配使用自由组合。主音量仍不持久化，不自动播放。


## 2026-10-11 备份合并恢复

使用说明 → 恢复备份。可选择本地 JSON 文件或粘贴完整内容。先预览新增组合、收藏、重复数量和版本冲突，再合并到本地方案。恢复过程不播放声音，不影响编辑器草稿或正在进行的会话。

- 导入与读取使用同一份 v1 校验，接受 UTF-8 BOM，保留合法的内置录音版本引用，剔除未使用字段。未知结构、错误元数据、重复 ID、无效参数或素材引用整体拒绝。
- 相同 ID 且内容相同的条目跳过；同 ID 的不同版本另存新 ID，保留原时间、修订号和声音参数。再次导入时识别已恢复副本，不重复添加。
- 收藏取并集，不移除本机收藏。不同 ID 的独立组合保留，即使名称相同。
- 使用既有跨页面锁，在正式写入时重新计算合并结果。容量和存储失败不做部分恢复。读取失败的已有本地数据保持原样，不通过导入自动覆盖。
- 文件内容只在本机读取，最大 600 万字节；解析内容仍受 150 万字符限制。输入变化后需重新查看恢复内容。
- 成功后展示实际恢复数量，键盘焦点移至结果；可直接打开我的方案。收起和再次打开保留本页输入，换页后清空。

验证涵盖粘贴及文件恢复、重复识别、刷新保留、恢复后播放和原有数据完整性，见 [备份恢复验收](verification/backup-restore-acceptance.md)。


## 2026-10-26 个人搭配与偏好

12 个单阶段内置方案支持「调整并保存搭配」。个人搭配草稿新增 `kind: 'preset'`，保存 `title`、`minutes` 和完整的 `template` 配方快照。使用独立的简洁编辑页调整名称、时长、声音层增益，其他声音参数保留。多阶段、重复流程与带完成音的配方拒绝转换。

播放时从快照复制并应用时长和名称；缩短时将淡入淡出限制在合法范围，延长回原长度时不会丢失原长渐弱。旧自由组合仍走既有生成规则，已有数据无需改写。新类型保存在同一 library v1 容器，当前版本的导出、导入、去重、版本冲突、删除撤销都支持两种草稿。旧版程序不能读取新个人搭配，应使用更新后的代码；旧格式数据在新版继续有效。

偏好使用独立的 `wave-platform.preference.v1.*` 键保存，按设置分别写入，避免不同页面更新不相关设置时互相覆盖。主音量只在用户完成调整时保存；方案时长只保存合法值；损坏设置回退默认。偏好不包含播放状态，不会恢复自动播放，也不纳入方案 JSON 备份。跨页面已开始的播放不会被其他页面的偏好修改突然改变，重新打开页面时加载最新偏好。
